# 双路帧率与取流板测（2026-10-28）

## 1. 同时自由采集（sensor → DDR3）

60.639 s、每 10 s 采一次，A/B 各推 1819 帧：

| 项 | A | B |
|---|---:|---:|
| 帧数 | 1819 | 1819 |
| 帧率 | **29.997 fps** | **29.997 fps** |
| 每 10 s 增量 | 303~304 | 303~304 |
| verdict `0xF4`/`0x184` | 0x20 | 0x20 |
| 每帧入队组数 `0x1A0`/`0x1C0` | 518400 | 518400 |
| 丢组 `0x1A4`/`0x1C4` | 0 | 0 |
| 打包占用 `0x1B4`/`0x1D4` | ≈3.33e6 拍 | ≈3.33e6 拍 |

$$2 \times 29.997 \times 2{,}592{,}768 \approx 155.6\ \mathrm{MB/s}$$

占 Gen2 ×2（约 1.0 GB/s 可用）的 15.6%，DDR 用户口 3.2 GB/s 的 4.9%。

## 3. 交替 one-shot 取流（单槽时代，已被 pair 通路取代）

30 对 A/B 交替 ARM/ACK：一对 A+B 224.95 ms（p95 257.33 ms），即 4.445 pair/s、每路 4.445 fps；
其中 A 等新帧 34.69 ms、B 等新帧 22.19 ms、每帧取帧+校验+写 PGM 约 46 ms。
这是单槽/单 pusher/单 ARM 额度下的上限，不是相机或 PCIe 的限制。

## 4. 坑：未 ACK 的 one-shot 会把选中路压到 15 fps

驱动 probe 自动 ARM 一次，推完进 HELD；主机没 ACK 时写者保护住槽，该路每隔一帧在 SOF 处进 `S_SKIP`，正好掉一半。
写 `0x110=session、0x10C=0xC0、0x108=0x2` 释放后立刻回到 30 fps。
**测帧率必须保证 `0x114=0`（IDLE）且没有未 ACK 的 HELD 帧。**
