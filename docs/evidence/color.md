# 彩色相位与后处理证据（2026-10-28，1080p ROI）

## 1. 相位判据：绿在哪条对角线

frame A 的 2×2 原始均值：

~~~text
(0,0)=31.32  (0,1)=56.72
(1,0)=56.68  (1,1)=35.85
~~~

- 两条绿对角只差 0.07%，主对角差 13.5%；马赛克里只有绿占两格 → 绿在反对角 `(0,1)/(1,0)`；
- 因此只可能是 **RGGB** 或 **BGGR**；`GBRG`/`GRBG` 会出品红/绿棋盘，直接排除。

## 2. R/B 归属：当前取 RGGB

同一间办公室同时被 A/B 两路看到，告示牌是天然同场景参照：

| 相位 | A 路告示牌 | B 路告示牌 |
|---|---|---|
| RGGB | 黄色 | 黄色 |
| BGGR | 蓝色 | 蓝色 |

同一块牌子不可能既黄又蓝，当前安装下只有 RGGB 让两边一致。

- 证据图：`color_contact.jpg`（A/B 并排彩色）；其余原图未归档。
- 反方证据来自 180° 翻转的旧预览/另一套安装（原图未归档），不能搬到当前帧；
- R10F 头 0x28 写 3(GBRG) 是 `SRC_BAYER_PHASE=0` 占位推导，**不是测量值**。

## 3. 后处理（`--auto`）

扣黑 12 → 灰世界 AWB（排除 max≥250 的过曝像素，R/B 增益夹 0.25..4.0、EMA 0.35）→ AE 目标 100 且只提亮 →
gamma 2.2 → 高光去饱和（输出 max>220 向亮度混合，最多 85%）→ 4×4 有序抖动。

旧固定增益 2400/2062 会让白墙偏米黄、告示牌偏紫，已改为逐帧灰世界。

## 4. 风险

换模组、改支架、改 MIPI 走线、改 ROI 奇偶（X0/Y0/SKIP_ROWS）后 R/B 可能翻转，必须用已知色卡重测；
`--bayer rggb|bggr` 可显式覆盖。没有 CCM/镜头校正/24 色卡标定，颜色只到「白参考 + 灰世界」级别。
